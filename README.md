Album Review Modeling Project:

OVERVIEW: The basis of this project is various text documents that contain notes I have taken for 3 years on a daily new album. The reviews range from multiple paragraphs to a few sentences and all have a 0-10 score.

DATA: txt files of music reviews (not on github)

GOAL: Experiment with NLP, Computer Vision on album artwork and various combined models to generate predictions on my 0-10 album score. The scores are highly subjective and this is more meant as a fun project than a possible goal within any real degree of accuracy.

STACK: The data is stored in a local Postgres database and pulled via SQLALCHEMY into a CONDA/Miniforge python environment run through the VS CODE IDE.

AI USAGE: Github Copilot was used for bug testing and syntax help, but the architecture and code structure was designed by me.
